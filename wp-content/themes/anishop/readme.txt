قالب فروشگاهی مدرن و سریع «آنی‌شاپ» برای سایت‌های موبایل‌فروشی و لوازم جانبی،
طراحی‌شده بر پایه ووکامرس و کاملاً راست‌چین (RTL) — بدون نیاز به المنتور یا صفحه‌ساز.

== Features ==

* طراحی مدرن فارسی و راست‌چین با فونت وزیرمتن
* صفحه اصلی کامل: اسلایدر، دسته‌بندی‌ها، پیشنهاد شگفت‌انگیز با تایمر، پرفروش‌ها، جدیدترین‌ها، برندها، وبلاگ
* هدر حرفه‌ای با نوار بالا، جستجوی محصول، سبد خرید و منوی موبایل کشویی
* کارت محصول سفارشی با نشان درصد تخفیف فارسی و نشان «جدید»
* قالب‌های اختصاصی فروشگاه، محصول، سبد خرید، پرداخت و حساب کاربری
* استپر تعداد با دکمه + و − در همه فرم‌ها
* تنظیمات سفارشی‌ساز: اطلاعات تماس، متن‌های صفحه اصلی، تصاویر اسلایدر، فوتر
* بدون هیچ وابستگی به افزونه صفحه‌ساز؛ سبک و سازگار با Page Cache

== Installation ==

1. پوشه قالب را در `wp-content/themes/anishop` قرار دهید (یا زیپ قالب را از «نمایش ← پوسته‌ها ← افزودن» نصب کنید).
2. افزونه WooCommerce را نصب و راه‌اندازی کنید و ویزارد آن را کامل کنید.
3. از «تنظیمات ← خواندن» یک برگه ثابت برای صفحه اصلی انتخاب کنید.
4. منوها را از «نمایش ← فهرست‌ها» به جایگاه‌های «منوی اصلی»، «منوی نوار بالا» و «فوتر» اختصاص دهید.
5. اطلاعات تماس، اسلایدر و متن‌ها را از «نمایش ← سفارشی‌سازی» تنظیم کنید.

== Widget areas ==

* ستون کناری فروشگاه — فیلترهای ووکامرس
* ستون کناری وبلاگ
* نوار بالای سایت
* نوار تبلیغاتی بالای فوتر

== Tips ==

* برای نمایش آیکون هر دسته، متای دسته `anishop_icon` را با یکی از نام‌های آیکون
  (phone, tablet, watch, audio, headset, gift, …) تنظید کنید.
* برندها از تاکسونومی `product_brand` یا `pa_brand` خوانده می‌شود.
* درصد تخفیف به‌صورت خودکار روی نشان «فروش ویژه» محاسبه می‌شود.
